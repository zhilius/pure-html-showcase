Fonts & Special Characters

How to use HTML entities, special characters, and phonetic annotations.

HTML Entities

HTML entities let you display reserved characters and special symbols:

&copy;  — ©
&reg;   — ®
&trade; — ™
&euro;  — €
&yen;   — ¥
&pound; — £
&larr;  — ←
&rarr;  — →
&infin; — ∞
&sum;   — ∑
&radic; — √
&pi;    — π
&Omega; — Ω
&alpha; — α
&beta;  — β
&ne;    — ≠
&le;    — ≤
&ge;    — ≥
&plusmn;— ±

Ruby Annotation

The <ruby> element provides phonetic annotations for East Asian typography:

<ruby>
  漢字<rp>(</rp><rt>kan-ji</rt><rp>)</rp>
</ruby>

Live demo: 漢字(kan-ji)

  • <ruby> — the container
  • <rt> — the pronunciation annotation
  • <rp> — fallback parentheses for browsers that don't support ruby
