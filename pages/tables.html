Tables & Data

How to structure tabular data using only HTML.

HTML Table Structure

Tables in HTML are built from rows (<tr>) and cells (<td> for data, <th> for headers). The full structure includes:

<table border="1" cellpadding="8">
  <caption>Most Used Languages in 2026</caption>
  <colgroup>
    <col>
    <col>
    <col>
  </colgroup>
  <thead>
    <tr>
      <th scope="col">Language</th>
      <th scope="col">Popularity</th>
      <th scope="col">Type</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Python</td>
      <td>96%</td>
      <td>General / AI</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="3">Source: TIOBE 2026</td>
    </tr>
  </tfoot>
</table>

Key Table Elements

  • <table> — the container
  • <caption> — table title/description
  • <colgroup> / <col> — column styling
  • <thead> — header section
  • <tbody> — body section
  • <tfoot> — footer section
  • <tr> — table row
  • <th> — header cell (with scope attribute)
  • <td> — data cell

Attributes

  • border — sets border width
  • cellpadding — space inside cells
  • cellspacing — space between cells
  • colspan — merge columns
  • rowspan — merge rows
  • scope="col" / scope="row" — accessibility
