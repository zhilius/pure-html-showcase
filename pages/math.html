∑ MathML — Math Formulas Rendered by the Browser

How to write mathematical notation using MathML, a native HTML math language.

What is MathML?

MathML (Mathematical Markup Language) lets you write mathematical formulas directly in HTML. The browser renders them natively — no images, no JavaScript.

Quadratic Formula

<math display="block"
     xmlns="http://www.w3.org/1998/Math/MathML">
  <mrow>
    <mi>x</mi>
    <mo>=</mo>
    <mfrac>
      <mrow>
        <mo>−</mo>
        <mi>b</mi>
        <mo>±</mo>
        <msqrt>
          <mrow>
            <msup>
              <mi>b</mi>
              <mn>2</mn>
            </msup>
            <mo>−</mo>
            <mn>4</mn>
            <mi>a</mi>
            <mi>c</mi>
          </mrow>
        </msqrt>
      </mrow>
      <mrow>
        <mn>2</mn>
        <mi>a</mi>
      </mrow>
    </mfrac>
  </mrow>
</math>

Key MathML Elements

  • <math> — the container
  • <mi> — identifier (variable)
  • <mn> — number
  • <mo> — operator (+, =, ∫, etc.)
  • <mfrac> — fraction
  • <msqrt> — square root
  • <msup> / <msub> — superscript / subscript
  • <msubsup> — both subscript and superscript (e.g., integrals)
  • <mrow> — groups elements horizontally
