Inline SVG — Vector Graphics Without External Images

How to embed vector graphics directly in HTML using SVG.

What is Inline SVG?

SVG (Scalable Vector Graphics) can be written directly inside HTML. No external files, no CSS, no JavaScript — just XML-based vector graphics rendered by the browser.

HTML Code

<svg viewBox="0 0 400 180"
     xmlns="http://www.w3.org/2000/svg">

  <defs>
    <linearGradient id="grad1"
      x1="0%" y1="0%" x2="100%" y2="100%">
      <stop offset="0%" stop-color="#ff6b6b"/>
      <stop offset="100%" stop-color="#4ecdc4"/>
    </linearGradient>
  </defs>

  <rect x="10" y="10" width="100" height="100"
        fill="url(#grad1)" rx="15"/>

  <circle cx="200" cy="60" r="50"
          fill="#ffd93d" stroke="#333" stroke-width="3"/>

  <polygon points="320,110 370,10 370,110"
           fill="#6c5ce7" opacity="0.85"/>

  <text x="200" y="150" text-anchor="middle"
        font-family="sans-serif" font-size="16">
    Pure SVG
  </text>

  <rect x="360" y="10" width="30" height="30"
        fill="#a29bfe" rx="5">
    <animate attributeName="y"
             values="10;140;10"
             dur="3s" repeatCount="indefinite"/>
  </rect>
</svg>

Key SVG Elements

  • <svg> — the canvas (with viewBox and xmlns)
  • <rect> — rectangle (with optional rx/ry for rounded corners)
  • <circle> — circle
  • <polygon> — polygon (any number of sides)
  • <text> — text
  • <defs> — definitions (gradients, filters, etc.)
  • <linearGradient> / <stop> — color gradients
  • <animate> — native animation (no JS needed!)
