Interactive Image Map

How to make clickable regions on an image using only HTML.

What is an Image Map?

An image map lets you define clickable areas (hotspots) on an image. Each area can link to a different URL or page section — no JavaScript needed.

HTML Code

<img src="image.png" usemap="#mymap"
     width="400" height="150"
     alt="Interactive map">

<map name="mymap">
  <area shape="rect"
        coords="0,0,133,150"
        href="#section1"
        alt="Section 1"
        title="Go to section 1">

  <area shape="rect"
        coords="134,0,266,150"
        href="#section2"
        alt="Section 2"
        title="Go to section 2">

  <area shape="rect"
        coords="267,0,400,150"
        href="#section3"
        alt="Section 3"
        title="Go to section 3">
</map>

Key Elements

  • <img usemap="#name"> — connects the image to a map
  • <map name="name"> — defines the clickable areas
  • <area> — defines a single hotspot

Area Shapes

  • rect — rectangle (coords: x1,y1,x2,y2)
  • circle — circle (coords: x,y,radius)
  • poly — polygon (coords: x1,y1,x2,y2,x3,y3,...)
