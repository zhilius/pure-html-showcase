Native Progress & Metrics

How to display progress bars and measurements using only HTML.

Progress vs Meter

HTML provides two native elements for showing measurements:

  • <progress> — for indeterminate or determinate progress (e.g., file upload)
  • <meter> — for scalar measurements within a known range (e.g., battery level)

Progress Element

<progress value="72" max="100">72%</progress>

Attributes:

  • value — current progress amount
  • max — total amount (default: 1)

Live demo: System load: 72% 72%

Meter Element

<meter value="0.3" min="0" max="1"
       low="0.25" high="0.75" optimum="1">
  30%
</meter>

Attributes:

  • value — current measurement
  • min / max — range boundaries
  • low / high — threshold boundaries
  • optimum — the optimal value

The browser visually indicates whether the value is in the low, medium, or high range based on these thresholds.

Live demo:

Battery: 30% 30% (low)

Temperature: 38.5°C 38.5°C
