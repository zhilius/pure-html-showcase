Native Browser Dialog

How to create modal dialogs using only the HTML <dialog> element.

What is the Dialog Element?

The <dialog> element creates a native modal or non-modal dialog box. It's fully functional with just HTML — no JavaScript required.

HTML Code

<dialog open>
  <h2>I'm a native dialog!</h2>
  <p>No JavaScript, no CSS: just pure HTML.</p>
  <form method="dialog">
    <button>Close</button>
  </form>
</dialog>

Key Attributes & Behavior

  • open — makes the dialog visible (without it, the dialog is hidden)
  • method="dialog" — on a form inside a dialog, this closes the dialog when submitted
