Picture — Responsive Images Without CSS

How to serve different images based on screen size using only HTML.

What is the Picture Element?

The <picture> element lets you define multiple image sources for different screen sizes, resolutions, or formats. The browser picks the best one — no CSS media queries needed.

HTML Code

<picture>
  <source media="(min-width: 800px)"
          srcset="desktop.jpg">

  <source media="(min-width: 400px)"
          srcset="tablet.jpg">

  <img src="mobile.jpg"
       loading="lazy"
       alt="Description of the image">
</picture>

How It Works

  1. The browser checks each <source> element from top to bottom
  2. It uses the first one whose media attribute matches the current viewport
  3. If no source matches, it falls back to the <img> element
  4. The <img> is required and provides the alt text for accessibility

Additional Features

You can also use type to serve different image formats:

<picture>
  <source type="image/webp" srcset="image.webp">
  <source type="image/jpeg" srcset="image.jpg">
  <img src="image.jpg" alt="Description">
</picture>

This lets you serve modern formats like WebP or AVIF while falling back to JPEG for older browsers.
