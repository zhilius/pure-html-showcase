Native Multimedia

How to embed audio and video using only HTML.

What are Native Multimedia Elements?

HTML5 introduced <audio> and <video> elements that let you embed media directly in the browser without plugins or JavaScript.

Audio Element

<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  Your browser does not support audio.
</audio>

The controls attribute adds play/pause, volume, and timeline controls natively.

Video Element

<video controls width="320" height="180">
  <source src="video.mp4" type="video/mp4">
  Your browser does not support video.
</video>

You can set width and height directly on the element. The controls attribute provides native playback controls.

Live demo:

Key Attributes

  • controls — show native playback controls
  • autoplay — start playback automatically
  • loop — loop the media
  • muted — start muted
  • poster (video only) — thumbnail before playback
  • preload — hint for preloading (none/metadata/auto)

Multiple Sources

You can provide multiple <source> elements for different formats. The browser will use the first one it supports:

<video controls>
  <source src="video.webm" type="video/webm">
  <source src="video.mp4" type="video/mp4">
  <source src="video.ogg" type="video/ogg">
  Your browser does not support video.
</video>
