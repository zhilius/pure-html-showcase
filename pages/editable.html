Contenteditable — Live Text Editing

How to make any HTML element editable directly in the browser using only HTML.

What is Contenteditable?

The contenteditable attribute makes any HTML element editable directly in the browser. Users can click on the text and type — no JavaScript, no textarea, just a native HTML feature.

HTML Code

<blockquote contenteditable="true"
            spellcheck="true"
            cite="https://example.com">
  <p>This text can be edited directly
     in the browser.</p>
</blockquote>

Attributes

  • contenteditable="true" — makes the element editable
  • spellcheck="true" — enables spellcheck while editing
