# Pure HTML Showcase

Demostración del poder del HTML puro — sin una sola línea de CSS ni JavaScript.

## Secciones

- Formulario interactivo nativo (inputs, validaciones, datalist)
- Multimedia nativa (audio, video)
- Tablas semánticas y datos (table, meter, progress)
- Tipografía y texto semántico (mark, del, ins, abbr, blockquote, dl, etc.)
- Mapa de imagen interactivo (map, area)
- Progreso y métricas nativas (progress, meter)
- Diálogo nativo (dialog)
- Listas y estructura (ol, ul, anidadas)
- Fuentes y caracteres especiales (address, ruby, entidades HTML)
- SVG inline — formas, degradados y animación SMIL
- MathML — fórmulas matemáticas nativas
- Picture — imágenes responsivas
- Contenteditable — edición de texto en vivo
- Details anidados — acordeón recursivo

## Buenas prácticas implementadas

- **SEO**: meta tags, Open Graph, Twitter Cards, canonical URL, favicon
- **Accesibilidad**: skip-to-content, landmarks (main, header, nav, footer, section), aria-label, heading hierarchy, hidden attribute
- **Performance**: lazy loading, preconnect, dns-prefetch
- **Semántica HTML5**: elementos con significado estructural
